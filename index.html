Module 02 · Editorial Readability

1. Long-Form Technical Prose, Margin Sidenotes & Callouts

Literata 440 · 65ch Measure

In traditional multi-region deployments, engineers face an uncomfortable binary choice between strict linearizability (which requires a cross-ocean Raft or Paxos round-trip on every read) and eventual consistency (which risks serving stale state minutes after a write has committed). Neither extreme matches how interactive applications actually behave.

What users and downstream microservices almost always require is read-your-own-writes monotonicity paired with a deterministic upper bound on staleness[S1]. If a client mutates a permission graph in Singapore, any subsequent read carrying a session vector greater than or equal to hlc_epoch: 109482910 must observe that mutation immediately, whereas unauthenticated public reads can safely read from an in-memory ring buffer within a 2,000ms lease window.

Why Atomic Epoch Swapping Eliminates Mutex Stalls

Standard concurrent LRU caches protect their doubly-linked eviction lists with a read-write mutex or sharded spinlock. Under bursty traffic, cache-line bouncing across 64-core EPYC sockets degrades throughput even when 95% of requests are hits[S2]. By replacing mutable linked lists with a pre-allocated ring of immutable snapshot slots, readers acquire data via a single Acquire atomic load without ever blocking a background WAL applier thread.

[S1] SIDENOTE · HLC EPOCHS

Hybrid Logical Clocks combine physical NTP wall time (48 bits) with a monotonic logical counter (16 bits), preventing clock-skew anomalies across edge nodes.

[S2] BENCHMARK · CACHE BOUNCING

Removing the RwLock on L1 metadata lookups reduced CPU L3 cache misses from 18.4% to 1.9% at 100k RPS.

Semantic Callout & Guardrail Taxonomy
Focal Rule · Lease Expiration

If an edge node fails to renew its WAL heartbeat within 2,000ms, it must immediately evict local ring slots and route reads to the regional quorum.

Verified Invariant · Monotonicity

A client presenting client_hlc > slot_hlc bypasses the ring buffer and triggers an asynchronous fast-forward barrier.

Operational Note · Memory Budget

Each 64-slot ring buffer consumes a fixed 512 MB hugepage allocation per worker process with zero heap fragmentation.

RECOMMENDED PATTERN Wait-Free Read

Load the active slot index via Ordering::Acquire and clone the immutable Arc<SnapshotPage> reference before deserializing fields.

ANTI-PATTERN · AVOID Mutex Serialization

Never hold a write guard across network I/O or WAL decompression; a single slow packet will stall all 64 reader threads on the socket.

07 return Ok(Arc::clone(&slot.page));
08 }
09 Err(ReadFallback::RouteToQuorum { region: "ap-southeast-1", observed_hlc: slot.hlc_watermark })
10}
