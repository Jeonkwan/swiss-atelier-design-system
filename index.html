Module 02 · Editorial Readability

02. Long-Form Technical Prose, Margin Sidenotes & Callouts

Literata 440 · 65ch Measure

In this illustrative design, engineers compare a local snapshot read with a quorum fallback. The intended reader is a storage engineer deciding which read path is eligible. The example does not establish a general latency or consistency guarantee for distributed storage.

The example proposes read-your-own-writes monotonicity paired with a deterministic upper bound on staleness[S1]. If a client mutates a permission graph in Singapore, any subsequent read carrying a session vector greater than or equal to hlc_epoch: 109482910 must satisfy that session watermark before returning a local result, whereas unauthenticated public reads may attempt a read from an in-memory ring buffer within a 2,000ms lease window.

Why This Example Separates Reads from Updates

The synthetic comparison assumes a sharded LRU protected by a lock. Its illustrative contention values are design inputs, not measurements[S2]. By replacing mutable linked lists with a pre-allocated ring of immutable snapshot slots, readers acquire data via a single Acquire atomic load in the proposed local read path; correctness and concurrency testing are outside this presentation example.

[S1] SIDENOTE · HLC EPOCHS

Here HLC means hybrid logical clock. The example carries a session watermark; a concrete clock encoding and clock-skew guarantees are unspecified.

[S2] SYNTHETIC BENCHMARK EXAMPLE

Synthetic L3 cache-miss fractions: 18.4% for the comparator and 1.9% for the proposed path at an assumed 100k requests/s. Source: fictional specimen inputs; period, sample size, and uncertainty unknown.

Semantic Callout & Guardrail Taxonomy
Focal Rule · Lease Expiration

If an edge node fails to renew its WAL heartbeat within 2,000ms, it must immediately evict local ring slots and route reads to the regional quorum.

Proposed Rule · Session Watermark

A client presenting client_hlc > slot_hlc bypasses the ring buffer and triggers an asynchronous fast-forward barrier.

Operational Note · Memory Budget

The example configuration assigns 512 MB per worker to a 64-slot ring. Allocation overhead and fragmentation have not been measured.

ILLUSTRATIVE RECOMMENDATION Wait-Free Read

Load the active slot index via Ordering::Acquire and clone the immutable Arc<SnapshotPage> reference before deserializing fields.

ANTI-PATTERN · AVOID Mutex Serialization

Never hold a write guard across network I/O or WAL decompression; a single slow packet will stall all 64 reader threads on the socket.

crates/edge-cache/src/ring_buffer.rs
Rust 1.82 · Wait-Free Atomic Path
01// Acquire the latest committed snapshot slot without locking the WAL writer thread
02#[inline(always)]
03pub fn read_monotonic(&self, min_hlc: HlcTimestamp) -> Result<Arc<SnapshotPage>, ReadFallback> {
04 let head_idx = self.active_epoch.load(Ordering::Acquire) & RING_MASK; // FOCAL: Zero-lock atomic load
05 let slot = unsafe { self.slots.get_unchecked(head_idx) }.load();
06 if slot.lease_valid_until() >= Instant::now() && slot.hlc_watermark >= min_hlc { // Proposed lease and session checks
07 return Ok(Arc::clone(&slot.page));
08 }
09 Err(ReadFallback::RouteToQuorum { region: "ap-southeast-1", observed_hlc: slot.hlc_watermark })
10}
